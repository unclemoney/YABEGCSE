# ArtLibrary

Placeholder for the YABEGCSE art library: the ~2,700 PNGs converted from the
GCS Mega Pack and DOS 1.3 assets, plus the palette identity file ($RP9A).

The library ships with the editor and runtime. Levels reference art by
**library-relative names only** — never embedded data, never absolute paths.
Unresolved references render as an obvious placeholder and log to the debug
panel.

Assembling this folder is a pre-handoff task (see *YABEGCSE Milestones and
CLI Prompts*, §0), gated on the final vga2png alpha-keying rerun.
